## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Establish a deliberately small visual system for the construction-business website before production implementation begins. Governing principle: less is more - this task produces just enough design direction to build a polished small-business website, not a large design system. The direction must be specific to this construction business and must explicitly discourage generic AI-generated website styling. By default avoid: gratuitous gradients, glassmorphism, excessive rounded cards, floating decorative shapes, excessive drop shadows, unnecessary animation, placing every section inside a card, and visual complexity added solely to make the site feel modern. Prefer instead: strong typography, quality construction/project photography, whitespace, clear hierarchy, direct calls to action, and restrained visual details. The direction must cover: typography direction; a restrained color palette; spacing and content-width conventions; primary and secondary button/link treatment; image treatment; page/section hierarchy; basic desktop and mobile layout direction; and the overall visual tone appropriate to this specific construction business. Out of scope for this task: production HTML/CSS/JS implementation, component libraries, framework adoption, elaborate design-system documentation, and speculative interactive effects.
